# KDP print rules used for the Wapella book (checked Nov 23, 2026 on kdp.amazon.com)

## Trim
- Hardcover sizes: 5.5x8.5, 6x9, 6.14x9.21, 7x10, **8.25x11**.
- Paperback table lists **8.5x11** but not 8.25x11 → build TWO interiors from the same content:
  - Paperback: 8.5 x 11 in
  - Hardcover: 8.25 x 11 in
- Page counts: paperback 8.5x11 B&W white 24–590; hardcover B&W 75–550 (hardcover needs ≥ 75 pages).

## Interior
- No bleed (images stay inside margins) → outside/top/bottom margins ≥ 0.25 in.
- Gutter (inside): 24–150 pp 0.375 in; 151–300 pp 0.5 in. Use ≥ 0.75 in inside anyway for comfort.
- Even page count; fonts embedded; images 300 DPI at printed size; grayscale.

## Paperback cover (white paper, B&W)
- Spine = pages × 0.002252 in.
- Full width = 0.125 + 8.5 + spine + 8.5 + 0.125; height = 11 + 0.25.
- Spine text only if ≥ 79 pages; 0.0625 in clear each side of spine text.
- Text ≥ 0.125 in inside trim; barcode area lower-right of back cover (KDP places 2 x 1.2 in white box).
- 300 DPI, single PDF, fonts embedded, no colour profile, no crop marks.

## Hardcover (case laminate) cover
- Wrap 0.51 in past each edge; safe margin 0.635 in from book edge; 0.4 in hinge each side of spine (no text).
- Spine width for hardcover comes only from KDP's cover calculator/template → final hardcover cover must be checked against the KDP template for the final page count.
- Barcode 2 x 1.2 in, ≥ 0.76 in from bottom, ≥ 0.25 in from hinge.
